# Supermodel REDUX

[Windows and Mac Workbench releases](../../releases/tag/v942) | [V942 manual and shortcuts](MANUAL-V942.md)

[Support on Ko-fi](https://ko-fi.com/aveycole) | [Buy Me a Coffee](https://buymeacoffee.com/aveycole)

Extract the Workbench ZIP and open **Supermodel Redux Workbench.exe**. The manual covers the required Model:Cycles OS 1.13 reference, feature selection, building, flashing, and panel shortcuts.

On macOS 15 or later, download the Apple Silicon or Intel ZIP and open **Supermodel REDUX Workbench.app** from Finder. The Mac ZIP includes the runtime, compiler, MIDI support, and a setup guide.
